## The server must match the game version {#version-match}

Enshrouded gets updates often, and a player can join your server only when their game is on the same version as the server. So after every update, the server and the players' games have to update together. Until the server is updated, a player who updated their game sees **server version too old**.

## We update your server for you {#automatic}

Your server follows Enshrouded's version on Steam. The **Game version** card on the **Overview** page shows the version installed on your server and the latest one available.

@[open](overview)

The default way to update is **When empty**: when an update comes out, we take a backup and update the game on our own once the server has been empty for a few minutes, or right away if it's stopped. We never stop the server while players are on it.

- To update right away without waiting, press **Update now** on the **Game version** card. The update drops everyone online, and Enshrouded can't warn them in the game, so tell them yourself.
- To update only when you say so, choose **Ask me** on the **Game updates** card of the **Manage** page. We notify you when each new version comes out.

> [!warning] With **Ask me**, your server stays on the older version until you update it, and friends who updated their game can't join.

> [!note] Your server can't go back to an older version. A player on an older version has to update their game.

## When friends can't join after an update {#after-patch}

1. Open the **Game version** card on the **Overview** page.
2. If it shows **Update available** or that it's waiting for players to leave, the server is on an older version than your friends' game, which is why they see **server version too old**. Press **Update now**.
3. If it shows **Up to date**, the player is the one on an older version. They update their game on Steam, then open it again and join.
