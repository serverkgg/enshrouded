# إنشراودد (Enshrouded)

يضم هذا الريبو كل ما تحتاجه منصة سيرفرك لتشغيل سيرفرات إنشراودد. سيرفر إنشراودد لماب مفتوح يغطيه ضباب قاتل، تستكشفه وتقاتل فيه وتبني قاعدتك مع أصحابك. حتى 16 لاعبًا في الماب نفسه، وتضبط من اللوحة الصعوبة وكلمات مرور الرتب والشات الصوتي، مع نسخ احتياطية تلقائية لمابك. ابنِ قاعدتك وواجه الضباب مع أصحابك، على سيرفر جاهز خلال دقائق. صفحة اللعبة: [serverk.gg/games/enshrouded](https://serverk.gg/games/enshrouded)

This repository holds everything Serverk needs to run Enshrouded servers. Enshrouded dedicated servers for an open world under a deadly fog, to explore, fight and build your base with your friends. Up to 16 players in one world, and the panel sets the difficulty, the role passwords and voice chat, with automatic backups of your world. Build your base and face the fog with your friends, on a server ready in minutes. Game page: [serverk.gg/games/enshrouded](https://serverk.gg/games/enshrouded)

## Layout

- `serverk.yml`: the game manifest with its metadata, resources, ports, backup and reset rules, and the guide list.
- `serverk.schema.json`: the JSON Schema of `serverk.yml` for the editor, written by `serverk-bridge schema`.
- `src/`: the driver, built on `@serverkgg/bridge`; `src/driver.ts` exports it and `src/main.ts` serves it.
- `image/Dockerfile`: the container image, with the compiled bridge as its entrypoint.
- `assets/`: the logo and the banner the site and the panel show.
- `guides/<id>/ar.md` and `en.md`: the guide bodies; each guide's title, summary and tags live in `serverk.yml`.

## Develop

Everything runs on [Bun](https://bun.sh).

- `bun install`: installs the dependencies, points Git at the hooks in `.githooks/` and writes `.claude/rules/package.md` from the bridge.
- `bun run check`: checks lint and formatting with Biome; `bun run fix` applies the fixes.
- `bun run tsc`: type-checks the code.
- `bun run test`: runs the tests.
- `bun run validate`: runs the checks the platform runs at publish, and fails while this README is out of date.
- `bun run compile`: builds `dist/bridge`, the linux/amd64 binary the image starts.

`.githooks/pre-commit` runs `bun run fix`, `bun run tsc`, `bun run test`, `bun run validate` and `bunx serverk-bridge schema --check` before every commit. There is no CI: a commit that passes the hook is ready.

`bun install` runs `serverk-bridge link`, which links `@serverkgg/bridge` to a sibling `serverk` checkout at `../serverk/modules/bridge` when one exists. Never commit a `file:` or `link:` dependency.

## Contribute

افتح issue لأي مشكلة أو اقتراح، بالعربية أو بالإنجليزية. ينشر فريق سيرفرك هذا الريبو من ريبو `serverk` بالأمر `bunx outdo package --prod --name enshrouded`، ويصل كل تغيير مدموج مع النشر التالي. العربية هي لغة المصدر: يُكتب كل نص يقرؤه العميل بالعربية أولًا، بلغة رسمية مع لمسة خليجية خفيفة، ثم بالإنجليزية. أبقِ أسماء الملفات والأوامر والمفاتيح بالحروف اللاتينية.

Open an issue for any problem or suggestion, in Arabic or English. Serverk releases this repository from `serverk` with `bunx outdo package --prod --name enshrouded`; merged changes ride the next release. Arabic is the source language: every string a customer reads is written in Arabic first, formal with a light Gulf touch, then in English. Keep file names, commands and config keys in Latin script.
